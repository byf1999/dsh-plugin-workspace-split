# 多工作区分屏视图

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web UI 插件：
在一个 `行 × 列` 网格里同时显示多个**真实会话**，把两三个工作区并排放在一屏里看，
而且每个格子都能直接对话、不是缩略图。

```
┌───────────────────────────┬───────────────────────────┐
│ 工作区 A · 会话 1         │ 工作区 B · 会话 2         │
│ ……对话内容……              │ ……对话内容……              │
│ ……输入框……                │ ……输入框……                │
├───────────────────────────┼───────────────────────────┤
│ 工作区 C · 会话 3         │ 工作区 D · 会话 4         │
└───────────────────────────┴───────────────────────────┘
```

## 功能

- **网格化实时会话**：1–3 列 × 1–3 行（最多 9 格），每格都是带输入框、可流式输出的真实会话。
- **可拖动布局**：拖动列间分隔条调整列宽；每列还各自保留自己的行高。
- **逐格切换**：每个格子可换工作区、换会话，用 `＋` 在该工作区新建会话，用 `↗` 把会话弹回普通单会话视图。
- **侧边栏联动**：分屏打开时，从左侧边栏打开会话会落到某个格子里，而不是替换整个分屏视图；
  工具栏按钮可以关掉这个联动。
- **格内文件预览**：会话里的文件链接会在本格内停靠一个只读阅读器（宽格在右侧、窄格在下方），
  分隔条可拖动；文本带行号与「加载更多」，图片直接显示，其它类型可「用系统应用打开」。
- **格内改动评审**：回答末尾「已编辑 N 个文件」卡片同样在本格内打开：列出本轮改动文件及增删行数，
  并可查看所选文件的统一 diff。
- **记住布局**：行列数、尺寸、各格会话、联动开关都保存在 `localStorage`（`dsh.workspace-split.v1`）。
- **中英文界面**：全部可见文案均已本地化。

## 兼容性

| 项目 | 要求 |
| --- | --- |
| Harness 运行时 | `>= 0.2.1-rc.3`（`engines.dsh`） |
| Harness 界面 | Web（`platform: "web"`，桌面端或浏览器） |
| React | 由 Harness 客户端模块表提供 |

插件渲染的是自带的会话视图，并读取若干客户端服务（`sessions`、`slots`、`locale`、
`workspaces`、`layout`，以及可选的 `remote`、`sidebarRight`、`uiWorkspace`）。
它们属于已发布的客户端 API，但不是冻结契约：超出声明范围升级 Harness 时可能需要同步更新插件。
服务缺失时插件会降级为「该格显示提示」，不会让整个主区域崩掉。

## 安装

- **插件市场**：在 Harness Web UI 打开 **插件 → 发现**，添加包含本插件的市场索引地址，
  找到「多工作区分屏视图」后点击安装，然后重启 DeepSeek Harness 让配置档重新加载 bundle。
- **plugin_manager 工具**：让 agent 调用 `plugin_manager` 的 `install_bundle`，
  target 填 `dsh-plugin-workspace-split`（从 npm 安装）或本目录的绝对路径（开发用 `link:` 安装），
  启用该 bundle 后重启。
- **本地开发**：直接把本目录作为 `link:` 依赖装进配置档即可，无需构建步骤
  （`client.js` 就是浏览器模块，`index.js` 是空的 Host 入口）。

## 卸载

在 **插件** 页禁用或移除该 bundle 即可：分屏面板消失，主区域回到普通单会话视图；
从配置档卸载包还会移除侧边栏面板按钮。`localStorage` 里的布局键可单独删除。

## 使用

1. 点左侧边栏面板列表里的四分格图标（在 *插件* / *计划任务* 下方）打开分屏视图。
2. 选择「列」和「行」（各 1–3）。首次出现的格子按工作区各填一个最近更新的会话；
   新格子继续在工作区之间轮转。手动清空的格子会保持空。
3. 拖动列间分隔条调整列宽（每列至少 12%）；双击分隔条，或聚焦后按 Enter/Space/Home 恢复均分；
   ←/→ 每次微调 2%。多行时每列还有独立的横向分隔条，只改这一列的行高。
4. 每个格子头部有：工作区选择（该工作区最新会话或新建）、按工作区分组的会话选择、
   `＋`（在该工作区新建会话）、`↗`（在普通视图中打开）。
5. 工具栏最右侧按钮切换**侧边栏联动**（默认开）。接收会话的格子依次为：你最后点击的格子、
   第一个空格子、已显示该工作区的格子、第 0 格；被接管的格子会闪一下。
6. 文件链接和回答末尾的「已编辑 N 个文件」会在本格内打开阅读器/评审。拖动细分隔条可调整占比
   （18–78%），双击（或聚焦后 Enter/Home）恢复默认，←/→ 微调 2%；`Esc` 或「关闭」收起。

## 实现要点

插件只有一个客户端模块（`client.js`）和一行 Host 入口。面板复刻自带的
`main` → `main.conversation` 链路：

```
main[key=workspace-split]              SplitView    （声明格子插槽）
  workspaceSplit.pane（会话作用域）     PaneHost → SessionProvider
    conversation.content 工厂           自带 Chat 视图（embedded 变体）
```

每格持有一个 Session 引用，并用 `SessionProvider` 标准座位绑定，
所以嵌入的会话跟随自己的会话，而不是主列当前选中的会话。

自带界面有两处假定右侧栏存在：文件链接与「改动评审」都调用
`sidebarRight.openResource(...)`。全局面板占用 `main` 时右侧栏并不存在，
因此插件包裹了该方法：文件地址转到格内阅读器，改动评审地址转到格内评审
（读取右侧栏自己的同源路由 `api/changes.summary` / `api/changes.diff`），
其它地址和错误保持原生行为。两个浮层均为只读，且不遮挡对话。

## 开发

```bash
npm run check    # 语法、manifest、中英文键对齐、CSS 引用、市场索引
npm run market   # 重新生成 market/index.json（需先填好仓库信息）
npm run pack     # 发布检查 + 在当前目录打出 npm tarball
```

没有打包器：`client.js` 由 Harness 客户端模块加载器直接加载
（`window.__ModuleLoader__.load({ id, factory })`，只允许 `require('react')`）。
界面文案在 `client.js` 的 `zh` / `en` 字典里；插件元数据在 `locale/en.json`、
`locale/zh.json`。

把 `localStorage['dsh.workspace-split.debug']` 设为 `'1'` 可打开降级路径的诊断日志。

## 已知限制

- 全局面板激活时右侧栏被卸载，其页签不可用；插件只覆盖上述两条点击路径。
- 联动开启时会拦截会话切换；用格子的 `↗` 或工具栏开关回到原生单会话行为。
- 改动 diff 只读，且一次显示一个文件。
- 这里用到的客户端服务是发布版 API，而非正式稳定契约。
